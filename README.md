EMBERLINE v2 — a wood-fired kitchen rush. One chef, one 2½-minute shift, a brick oven that never cools down. Grab ingredients, chop, grill and fry, build each dish on a plate at the plating bar, and serve it at the window before the ticket walks out. Six recipes unlock through the shift, tickets carry modifiers (+ extra cheese, no lettuce, double patty), rush hour hits at one minute, food burns if you leave it on the grill, and clean plates only come back when you wash the dirty ones at the sink.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — walk with WASD / arrows, or click where to go; press E to use a station.
